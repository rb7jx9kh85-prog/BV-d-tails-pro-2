# BV Détail Pro

Ce dépôt est prêt pour un déploiement statique sur Vercel.

## Organisation

- `index.html` : page d'entrée du site publiée par Vercel.
- `BV Détail Pro_files/` : ressources locales utilisées par `index.html`.
- `vercel.json` : configuration du déploiement statique, sans étape de compilation.

Les liens entre la page et ses ressources utilisent des chemins relatifs, afin que le site fonctionne sur le domaine Vercel comme sur un domaine personnalisé.
